# Laptop Performance Issues

## Problem
Laptop has become slow, unresponsive, overheating, or takes an unusually long time to boot or open applications.

## Common Symptoms
- Applications take a long time to open or freeze frequently
- Fan running constantly at high speed / laptop feels hot
- Boot time significantly longer than usual
- High disk or CPU usage shown in Task Manager even when idle
- Low available storage space warnings

## Possible Causes
- Too many startup applications launching automatically
- Pending Windows/antivirus updates running in the background
- Low disk space (especially below 10% free)
- Malware or unwanted background processes
- Outdated drivers, especially graphics and chipset drivers
- Hardware nearing end of life (older laptops, failing storage drive)

## Troubleshooting Steps
1. Open Task Manager (Ctrl+Shift+Esc) and check the Processes tab sorted by CPU and Memory usage to identify any single process consuming excessive resources.
2. Check available disk space; if below 10%, clear temporary files via Disk Cleanup or remove large unused files.
3. Disable unnecessary startup applications: Task Manager → Startup apps tab → disable non-essential items.
4. Confirm Windows Update and antivirus scans are not actively running in the background (these can temporarily spike usage).
5. Restart the laptop — this alone resolves many temporary slowdowns caused by memory leaks or stuck processes.
6. Check for and install pending driver updates via Windows Update or the manufacturer's support tool.
7. Run a full antivirus/malware scan if slowness is unexplained and persistent.

## Resolution
Restarting the machine and clearing startup bloat resolves most everyday slowness. Persistent slowness after these steps typically points to a hardware or storage issue requiring IT hardware diagnostics.

## Warnings
- Do not manually delete unfamiliar system files or processes without confirming what they are — this can cause system instability.
- Do not run unknown "PC cleaner" or "speed booster" tools; use only IT-approved utilities.

## Escalation Conditions
- Escalate for hardware diagnostics if the machine remains slow after a restart, disk cleanup, and driver updates.
- Escalate if malware is detected during a scan.
- Escalate if the laptop is more than 4 years old and performance issues are recurring (may need replacement, not troubleshooting).
